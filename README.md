# Econ 148 Final Project – Reproducing *Good, Bad, and Ugly Colonial Activities*

## Overview

This project is part of the final assignment for UC Berkeley's Econ 148 course. Our team reproduces key findings from the published study:

> Miriam Bruhn & Francisco A. Gallego (2012). *Good, Bad, and Ugly Colonial Activities: Do They Matter for Economic Development?*  
> *The Review of Economics and Statistics*, 94(2), 433–461.

Our goal is to ensure **computational reproducibility**—replicating the original paper’s tables and regression results using the same datasets and methodology.

---

## Key File

🧠 **All code used to generate tables and results is contained in** `replicate.ipynb`.

This notebook:
- Loads and processes the dataset.
- Reproduces the regressions and summary statistics from the original paper.
- Outputs LaTeX tables into the `texFiles/` folder.

---

## How to Reproduce

1. Ensure you have all necessary files in the same structure shown above.
2. Open `replicate.ipynb` in a Jupyter environment (e.g., Jupyter Lab, VS Code, or Google Colab).
3. Run all cells from top to bottom.
4. Generated `.tex` tables will appear in the `texFiles/` folder.
